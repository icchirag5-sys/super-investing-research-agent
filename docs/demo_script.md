## 2:00-2:25  A design decision I'm proud of
"I kept the facts and the writing separate. Code does the checking: dates, flagged sources, recalculating the table,
and a validator that checks every number in the brief against the exact chunk it cites. The model only does the writing.
So when the model slips, the validator catches it, instead of me hoping the prompt works."
